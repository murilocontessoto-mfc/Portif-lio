# Portfólio - Murilo Contessotto

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar minha trajetória como estudante de Desenvolvimento de Sistemas, destacando meus conhecimentos, aprendizados, cursos, projetos e experiências adquiridas durante minha formação na ETEC.

O objetivo é organizar e apresentar minha evolução na área da tecnologia, demonstrando na prática os conhecimentos desenvolvidos ao longo do curso.

## 👨‍💻 Sobre mim

Meu nome é Murilo Contessotto e sou estudante do curso de Desenvolvimento de Sistemas na ETEC Pedro Álvares Ferreira, localizada no prédio da FATEC.

Tenho interesse pela área da tecnologia e gosto de aprender coisas novas relacionadas à programação e ao desenvolvimento de sistemas. Durante minha formação, venho adquirindo conhecimentos em desenvolvimento web, banco de dados, algoritmos e eletrônica.

Além dos estudos, gosto de jogar basquete e busco constantemente aprimorar minhas habilidades e adquirir novas experiências.

## 🖥️ Tecnologias utilizadas

As principais tecnologias utilizadas no desenvolvimento do portfólio foram:

- **HTML5:** Estruturação e organização das páginas do site.
- **CSS3:** Estilização, cores, posicionamento de elementos, animações e organização visual.
- **JavaScript:** Tecnologia estudada durante minha formação em Desenvolvimento de Sistemas.

## 📂 Estrutura do projeto

O portfólio é dividido em seis páginas principais:

1. **Início (`index.html`):** Página inicial com uma apresentação pessoal, imagem e atalhos para acessar outras partes do portfólio.
2. **Sobre mim (`sobre.html`):** Apresenta informações pessoais, minha trajetória acadêmica, meus estudos e interesses.
3. **Aprendizado (`aprendizado.html`):** Mostra as tecnologias que venho estudando, como HTML, CSS, JavaScript e Banco de Dados, além dos conhecimentos adquiridos nas disciplinas da ETEC.
4. **Cursos (`cursos.html`):** Apresenta os cursos realizados, divididos entre cursos da ETEC e cursos externos, incluindo plataformas, cargas horárias e situações de conclusão.
5. **Projetos (`projetos.html`):** Apresenta projetos desenvolvidos durante minha formação, com destaque para a Bobina de Tesla Musical, realizada para a ExpoETEC.
6. **Relatórios (`Relatório.html`):** Reúne relatórios de palestras, apresentações e eventos dos quais participei durante minha formação acadêmica.

## 🎨 Características do projeto

- Menu de navegação compartilhado entre as páginas.
- Identidade visual baseada nas cores azul, branco e preto.
- Organização dos conteúdos em seções.
- Cartões para apresentação de informações e projetos.
- Listas organizadas para cursos e relatórios.
- Layout adaptável a diferentes tamanhos de tela.
